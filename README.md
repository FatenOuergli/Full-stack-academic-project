# Pâtisserie Maison

Academic full-stack project: an online shop for a traditional Tunisian pâtisserie (baklawa, makroudh, kaak warka, ghraiba…), with prices and payments in Tunisian dinars (TND).

| Folder | Content | Status |
| --- | --- | --- |
| [`docs/SPEC.md`](docs/SPEC.md) | Conception and modelling (actors, business rules, schema, API contract, security, phase plan) | Done |
| `patisserie-api/` | Express + MongoDB REST API | Phases 3 to 8 |
| `patisserie-web/` | Angular client | Phases 9 to 12 |

Progress is tracked phase by phase in [`docs/PROGRESS.md`](docs/PROGRESS.md). To run the API, see [`patisserie-api/README.md`](patisserie-api/README.md).
